# Noor — Personal Website

A responsive personal website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — colors, typography, layout, and responsive styling
- `script.js` — mobile navigation and automatic footer year

## Run it
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Edit the text and styles as you like.

## Personalize before publishing
- Replace the illustrated placeholder in the hero with a photo you want to use. The current image is made entirely with CSS, so the page works without image assets.
- Add links to any other social accounts you want to show.
- Add future projects in the Projects section when they are ready.
- Update the language proficiency labels if you want more precise descriptions.
- Add a real CV PDF link if/when you want a downloadable resume button.

## Design notes
The visual direction uses a warm paper background, muted rose, dusty blue, navy, editorial serif headings, and small monospace labels. Google Fonts are loaded online; fallback fonts are included for offline use.

The site does not use a framework, build step, database, or external JavaScript library.
